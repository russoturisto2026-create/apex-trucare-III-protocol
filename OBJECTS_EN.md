# Breakdown map of pump response objects

Byte-by-byte representation of every frame the pump sends: response objects (class `a3`), class `a1`
frames — acknowledgments and notifications (PROTOCOL_EN.md §4.12) — and the "heartbeat" (`a5/03`). Shows
**how fully each frame has been parsed**. Each field's raw value is given so conclusions can be checked
against the data rather than taken on faith.

Notation: **C** — bytes are constant across the window; **V** — bytes vary. Status: 🟢 confirmed · 🟡
assumption · 🔲 unparsed. `off` — offset within the data payload (after the 6-byte frame header, before
the CRC). The insulin dosing unit is 0.025 U; see PROTOCOL_EN.md §2, §4.

**Data:** all archived captures from the study window (since 2026-09-16 16:34). Tables are generated by
`tools/gen_tables.py`; labels for parsed fields are taken from the `tools/fields.py` registry; they are
not edited by hand.
