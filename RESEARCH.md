# Протокол исследования

Хронологический журнал исследования протокола взаимодействия помпы **Apex Trucare III** и
приложения **Erwin Blueberry**. Одна запись — один шаг (и один коммит). Каждый шаг ссылается на
исходные материалы по номерам из `MATERIALS.md`; выводы шага переносятся в `PROTOCOL.md` со
ссылкой на этот шаг.

Правила ведения — в `README.md`. Ключевое: вывод получает статус **«подтверждено»** только после
≥2 измерений с различными характеристиками (правило 8); до этого — **«предположение»**.

Легенда статусов: 🟡 предположение · 🟢 подтверждено · 🔴 требует перепроверки.
